# Smart Hiking Companion

A comprehensive, mobile-first hiking application built with Next.js, TypeScript, and Tailwind CSS.

## Features

- **Interactive Maps**: Topographic maps with GPX alignment using Leaflet.
- **Real-time Tracking**: GPS tracking to show your location on the trail.
- **Elevation Profiles**: Interactive charts showing elevation gain/loss.
- **Weather Forecasts**: Altitude-adjusted weather estimation.
- **PWA Support**: Installable on mobile devices with offline capabilities.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) with your browser.

## Project Structure

- `src/components/Map`: Map and GPX logic.
- `src/components/Mountain`: Mountain detail components.
- `src/components/Weather`: Weather widgets.
- `public/gpx`: Sample GPX files.

## technologies
